# HWPX 표 잘림 사전점검

AI로 채운 한글(HWPX) 서식을 한글에서 열기 전에, 표가 잘리거나 파일이 안 열릴 신호부터 보는 웹 도구입니다.

**바로 쓰기: https://byungwoongyoo.github.io/hwpx-precheck/**

- 파일은 브라우저 안에서만 읽습니다. 서버로 올리지 않고, 외부 요청도 보내지 않습니다(`index.html` 한 파일).
- 한글로 문서를 그려 보지 않습니다. 파일 속 설정값과 글자 수로 높이를 어림하므로, 경고가 있어도 정상일 수 있고 없어도 깨질 수 있습니다.

## 보는 것

| 규칙 | 보는 것 |
|---|---|
| S1 | 머리 정보(`header.xml`)가 선언한 섹션 수와 실제 섹션 파일 수가 다른지, 머리 정보 파일이 있는지 |
| T1 | ‘글자처럼 취급’(`treatAsChar=1`) 표가 한 쪽 높이에 가깝거나 넘는지 |
| T2 | ‘나누지 않음’(`pageBreak=NONE`) 표가 한 쪽보다 긴지, ‘행 단위로 나눔’(`pageBreak=TABLE`) 표에 한 쪽보다 긴 행이 있는지 |

규칙은 공모전·지원사업 서식을 AI로 채우다가 실제 한글 2024에서 겪은 실패에서 나왔습니다.

## 맞춰 본 결과 (2026-11-25)

한글이 직접 저장한 공개 시험 파일([python-hwpx](https://github.com/airmang/python-hwpx) `tests/fixtures/hancom_saved`, 1,265개)에서, 한글이 저장한 표 크기를 실제 높이로 보고 비교했습니다.

| 규칙 | 대상 표 | 실제로 한 쪽보다 긴 표를 잡음 | 놓침 | 잘못 잡음 |
|---|---|---|---|---|
| T1 | 글자처럼 취급 2,368개 | 10 | 0 | 1 |
| T2 (나누지 않음) | 21개 | 1 | 0 | 2 |
| T2 (행 단위, 긴 행) | 77개 | 해당 사례 없음 | – | 0 |

python-hwpx·HwpForge 저장소의 공개 HWPX 1,454개 전체에서는 47개(3.2%)에 신호가 나왔습니다. 일부러 깨뜨린 시험 파일 3개는 읽지 못했다고 표시합니다.
